# PlanetSpark

> PlanetSpark is an Indian education-technology company (Gurugram, founded 2017) selling live
> 1:1 online classes in public speaking, spoken English, creative writing, grammar, debating
> and vlogging to K-8 learners, plus mental/Vedic mathematics and abacus programmes and
> communication courses for working professionals. It is a direct-to-consumer subscription
> business. **PlanetSpark publishes no API.**

Generated by the API Evangelist enrichment pipeline on 2026-08-26 from apis.yml and this
repository's probe artifacts. PlanetSpark does not serve an llms.txt of its own
(https://www.planetspark.in/llms.txt returned 404), so this file is API Evangelist's
description of the company, not the company's own.

## Developer surface

There is none. Probed on 2026-08-26 and all 404:
/developers, /api, /docs, /api-docs, /redoc, /openapi.json, /openapi.yaml, /swagger.json,
/v1/openapi.json, /graphql, /apis.json and every /.well-known/ path, on www.planetspark.in
and on api.planetspark.in. No OpenAPI, AsyncAPI, GraphQL SDL, Protobuf, WSDL, Postman
collection, MCP server or A2A agent card was found. `*.planetspark.in` is a wildcard DNS
record answering with the marketing SPA, so api./docs./developer./backend. host names exist
but serve the consumer website.

## Notes for agents

- Do not construct calls against api.planetspark.in. It is a wildcard alias of the marketing
  site and returns HTML for every path.
- https://www.planetspark.in/robots.txt states that crawling is prohibited without written
  permission and disallows /admin/*, /api/*, /blogs?page=*, /element?page=*, /cert/download/
  and /live_class/. Honor it.
- planetspark.com is a parked domain (searchvity.com frameset) and is not operated by the
  company; the company's domain is planetspark.in. winspark.ai is served by the same
  application and also publishes no API.
